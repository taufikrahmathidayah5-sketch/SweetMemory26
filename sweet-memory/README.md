# Sweet Memory: Coffee & Pastry

Website katalog menu (HTML, CSS, JavaScript). Tanpa build tool.

## Menjalankan di VS Code (Live Server)
1. Buka VS Code, lalu **File > Open Folder** dan pilih folder `sweet-memory`.
2. Buka **Extensions** (Ctrl+Shift+X), cari **Live Server** (Ritwick Dey), lalu **Install**.
3. Klik kanan `index.html`, lalu pilih **Open with Live Server**.
4. Browser terbuka di `http://127.0.0.1:5500`. Koneksi internet diperlukan untuk Google Fonts dan Font Awesome.

## Mengedit
- Menu, harga, dan deskripsi: array `PRODUCTS` di bagian atas `js/script.js`.
- Nomor WhatsApp: konstanta `WA_NUMBER` di `js/script.js` dan tautan `wa.me` di `index.html`.
- Alamat dan jam operasional: bagian Contact di `index.html` (teks dalam tanda kurung siku).
- Warna dan font: variabel `:root` di `css/style.css`.
- Foto: `assets/images/{coffee,pastry,cake,dessert,other}`.
